Каталог космических миссий 🚀
Учебный проект на Python для работы с базой данных космических кораблей и миссий.

Что умеет программа:
Выводить полный список всех запланированных и прошедших космических миссий с номерами.
Искать миссии по конкретному направлению (например: Марс, Луна, дальний космос).
Работать в удобном интерактивном меню в консоли.
Запуск проекта
Запустите файл main.py в среде разработки PyCharm или через терминал с помощью команды: python main.py
