Каталог идей для Python-проектов
Это учебное консольное приложение, которое помогает хранить, просматривать и добавлять новые идеи для разработки.

Инструкция по запуску
Установите Python версии 3.x.
Запустите главный файл программы: python main.py.
Используйте интерактивное меню в консоли (пункты 1-3) для управления каталогом
